# Notation

## Groups and spaces

- `G`: a group, usually written multiplicatively.
- `S`: an abelian group, semigroup, or vector space when the context is additive.
- `X,Y,E`: normed spaces; completeness is stated explicitly when required.
- `K`: a complete non-Archimedean normed field.
- `‖·‖`: norm; `‖·‖∞`: uniform/supremum norm.

## Functional defects

- Quadratic group defect: `q(xy)+q(xy⁻¹)-2q(x)-2q(y)`.
- Jordan defect: `f(x+y)+f(x-y)-2f(x)-2f(y)`.
- Pexider defect: `f(s+t)-g(s)-h(t)`.
- Four-function defect: `F(x+y)+G(x-y)-L(x)-M(y)`.
- Cosine–sine defect: `f(xy)-f(x)g(y)-g(x)f(y)-h(x)h(y)`.

## Special classes

- `Tor(G)`: finite-order elements.
- Periodic group: every element has finite order.
- Dyadically eventually commuting: `(xy)^(2^n)=x^(2^n)y^(2^n)` for all sufficiently large `n`, with `n` allowed to depend on `x,y`.
- `n`-Abelian: `(xy)^n=x^n y^n` for one fixed `n` and all `x,y`.

## Cone notation

- `v(a)={b:b≤a+v}`.
- `(a)v={b:a≤b+v}`.
- `v(a)v=v(a)∩(a)v`.
