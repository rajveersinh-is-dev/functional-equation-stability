# Submission checklist

## Manuscript

- [x] Title and author supplied.
- [x] Abstract and keywords supplied.
- [x] Introduction, motivation, background, and literature comparison included.
- [x] Definitions and normalization stated precisely.
- [x] Main theorem, complete proof, uniqueness corollary, and sharpness examples included.
- [x] Limitations and open questions included.
- [x] Bibliography compiled without undefined citations.
- [x] PDF generated and text-inspected.

## Verification and reproducibility

- [x] Lean 4.36.0 and Mathlib v4.36.0 pinned.
- [x] Central theorem, exact structure, sharpness lower bounds, and uniqueness corollary compile.
- [x] Axiom audit reports only standard logical axioms.
- [x] Python tests and lint pass locally.
- [x] Computational outputs and reproduction commands included.
- [ ] GitHub Actions results verified after publication.

## Journal-specific preparation

- [ ] Choose one journal from the shortlist.
- [ ] Recheck current fees, formatting, abstract length, and archiving policy.
- [ ] Convert references and LaTeX style to the journal template if required.
- [ ] Add any required declarations, ORCID, and AI-use statement.
- [ ] Obtain separate human authorization before actual submission.

## Explicitly not claimed

- No journal acceptance.
- No external expert peer review.
- No institutional affiliation or endorsement.
- No automatic submission.
